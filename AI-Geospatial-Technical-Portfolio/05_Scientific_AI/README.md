# 05 | Evidence-aware scientific AI and molecular screening

## Research objective

Explore how molecular structure representations, machine learning and computational evidence checks can prioritize candidates for experimental investigation.

## Technical approach

The research includes molecular identity and structure standardization, fingerprint and descriptor generation, supervised activity prediction and computational screening. Candidate identity, input quality and applicability-domain limitations are treated separately from predictive scores.

```mermaid
flowchart LR
    A[Molecular records] --> B[Identity and structure checks]
    B --> C[Fingerprints and descriptors]
    C --> D[Predictive modeling]
    D --> E[Candidate prioritization]
    E --> F[Experimental review]
```

## Engineering relevance

This case demonstrates transferable work on heterogeneous scientific data, reproducible feature generation, model evaluation and evidence-aware candidate review. The same discipline is useful in municipal AI when data quality and uncertainty matter.

## Evidence boundary

Computational predictions are hypotheses, not demonstrated biological activity or clinical benefit. Experimental validation remains necessary. No proprietary molecular structures, target-specific candidate lists, unpublished inventions, internal datasets or non-public model code are included.
